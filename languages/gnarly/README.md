# Gnarly Language

Parent: [Zedge Languages](../README.md)

Children:
- [Queries](./queries/README.md)

The Gnarly language registration binds `.gnarly` files to the shared Gnosis
grammar and `gnosis-lsp`. It keeps GG-compatible node and edge syntax while
adding Gnarly metadata, embedded implementation blocks, Babelfish code actions,
and speed-hint diagnostics.
